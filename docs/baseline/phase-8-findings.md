## 3. What the review caught, and behaviour changes to know about

- **Icon buttons were squeezed to a 2 px glyph (a Phase 7 and older defect).** A link styled with `buttonVariants({ shape: "icon" })` kept the size padding (`px-4` or `px-3` beats `px-0` in the generated CSS), so the back arrow of every editor, the Phase 7 article editor included, and the row edit icons of the lists rendered as a dot. Fixed once in `button-variants.ts` (`px-0!`); a console spec now asserts the back link has a real box and glyph on all four editors. `Button shape="icon"` was never affected because it merges classes.
- Site and Page editors: the button order is now Discard, Save, Preview, Publish (was Preview, Publish, Discard, Save); the bar is `role=group` "Editor actions" (was a region "Publishing controls"); validation links jump to the field by anchor (a field with no `id` no longer scrolls); the "Unsaved" and "Read only" badges are gone from the header ("No unsaved changes" is in the bar).
- Media: the Table and Grid toggle is two chip buttons with the same labels and `aria-pressed`; a deleted tile now carries a "deleted" mark (opacity was the only signal); the grid error reads "Could not load media" and an empty library offers Upload; "Reset search and filters" moved into the filter row.
- Lists are titled Projects, Case studies, Articles and Videos; the metadata placeholder `#102a43` became `#RRGGBB` (the lint read it as a colour literal).
- Video radio tiles show their checked state with a heavier frame and a mark, and show focus on the tile (they were `sr-only`).

## 5. Not done (the stop rule) and open

- **Inbox and moderation are a table plus drawer, not master-detail (C4).** A real master-detail would move the detail load, abort and focus-return logic out of the drawer. So there are no `j`, `k` or `e` shortcuts either.
- **`repeatable-record-editor` is not a full C3 editor** (services, FAQs and the like): no section index, unsaved count or Cmd/Ctrl+S. The first two are about 15 lines; the index needs `EditorialPanel` to expose a section id. Settings has no Cmd/Ctrl+S or unsaved bar (it would need an initial-values snapshot).
- The Site editor's inner repeatable rows keep their bordered cards (lint-clean; reorganising them is not a restyle). Case-study and video field errors stay inline with `role="alert"` because existing tests expect a single alert.
- `DataTable` still renders its own `rounded-xl` and shadow classes, which the console CSS neutralises; the sweep tests assert palette classes only.
- **Three near-identical notice components** (`ConsoleNotice`, `WorkspaceNotice`, `EditorialNotice`): merge into one when convenient.
- The unsaved-changes navigation guard (`beforeunload` plus link capture, R21) is not built; the "N unsaved changes" label is.
- Content workspaces still do not read filters from the URL, so most "Needs attention" links stay unfiltered (open since Phase 7).
- The sticky action-bar offset on the long project and case-study forms, and the video radio tiles, were not checked on a phone.
